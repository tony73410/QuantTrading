# Glossary

- **Formal code / 正式代码**：可被产品运行路径调用的实现，只能位于 `src/`。
- **Module / 模块**：具有明确职责、公共接口、依赖边界及对应文档的正式代码单元。
- **Public interface / 公共接口**：其他模块或外部调用方被允许依赖的稳定入口、数据结构或行为约定。
- **Runtime artifact / 运行产物**：执行时产生的日志、缓存、临时状态或报告，不属于源代码。
- **ADR**：Architecture Decision Record，用于记录影响长期结构的重要决定。
- **Paper trading / 模拟交易**：不向真实市场提交订单的模拟执行模式；它不等同于实盘授权。
- **Live trading / 实盘交易**：连接真实账户或可能影响真实资金的操作，始终需要明确批准和显式保护。
- **Execution environment / 执行环境**：未来订单执行所针对的隔离环境；当前默认标识为 Alpaca Paper，Alpaca Live 关闭。环境标识不代表执行模块已经实现。
- **Manual confirmation / 人工确认**：任何未来订单提交前必须由用户明确检查和确认；当前默认要求开启。
- **Bar / K线数据点**：某个固定时间粒度内的开盘、最高、最低、收盘、成交量及可选 VWAP/成交笔数汇总，不是逐笔成交。
- **Timeframe / 时间粒度**：每根 Bar 聚合的时间长度；当前行情浏览器支持 10 Minute、30 Minute、1 Hour、1 Day、1 Week 和 1 Month。
- **Adjustment / 价格调整（复权）**：针对拆股、分红等公司行动调整历史价格的口径；不同口径不得混用。
- **Feed / 数据源线路**：Alpaca 提供的行情来源，例如 IEX 或 SIP；不同 Feed 的覆盖和权限可能不同。
- **Coverage / 本地覆盖区间**：已成功完整请求并写入的 `[start, end)` 时间范围；周末/假日没有 Bar 不代表 Coverage 损坏。
- **Force Refresh / 强制刷新**：不先删除旧数据，重新请求所选范围并在验证成功后 upsert；失败保留旧数据。
- **Factor / 因子**：截至指定时间、只描述单一资产量化特征的版本化结果；它不是买卖建议。
- **FactorSnapshot / 因子快照**：记录股票、as-of时间、粒度、因子名称/版本/参数/状态和数据范围的稳定合同，是Factor层与Decision层之间唯一通信边界。
- **TradeIntent / 交易意图**：Decision层输出的可追溯建议方向；不是订单、风险批准、已提交交易或成交。
- **Target Adjustment Decision / 目标调整决策**：Phase 5D把一个显式选中的Phase 5C目标持仓差额按精确正/负/零映射为`INCREASE`/`DECREASE`/`HOLD`的专用研究结果；不含容差、舍入或EXIT规则。
- **TargetAdjustmentTradeIntent / 目标调整专用意图**：Phase 5D对非零精确差额保存的专用不可变研究证据；其金额等于差额绝对值。它不是通用`TradeIntent`；只有Phase 6A非批准结构门可读取，Backtesting、Accounting和Execution不能消费。
- **Target Adjustment Risk Manual-Review Gate / 目标调整风险人工审查门**：Phase 6A对一个显式Phase 5D专用intent执行来源链、非执行安全状态和数值Risk策略缺失检查的类型独立研究边界；安全有效结果固定要求人工审查，不产生批准金额或批准意图。
- **Single-Asset Exposure-Cap Definition / 单股暴露上限定义**：Phase 6B中用户显式保存的某股票正Decimal USD最大目标暴露不可变版本；无默认金额、Active版本或账户派生含义。
- **Cap-constrained candidate / 上限约束候选金额**：`MAX_TARGET_EXPOSURE_USD@1`保持、缩小或将原Phase 5D建议归零后的研究输出；它始终不大于原建议，正数时仍须人工审查，不是`approved_notional_usd`或可执行对象。
- **Research Asset Cash-Floor Definition / 研究资产现金底线定义**：Phase 6C中用户显式保存的某股票有限非负Decimal USD假设研究剩余底线不可变版本；显式零是有效版本值，不是缺省值，也不是账户、Accounting或Broker现金。
- **Research Asset-Cash Availability / 研究股票现金可用量**：Phase 6D从用户显式选择的Phase 3A计划精确最新守恒快照复制的同股票`ASSET_CASH`规划余额。它只用于第三条研究Risk约束，`research_cash_reserved=false`，不是账户、券商、已结算或可执行现金。
- **Cash-floor-constrained candidate / 底线约束候选金额**：`MIN_RESEARCH_ASSET_CASH_USD@1`在不重算Phase 6B规则1的前提下，使用精确Phase 5C人工研究资金基数保持、缩小或阻止原正候选；正数仍须人工审查，它不是完整Risk批准或可执行对象。
- **RiskDecision / 风险裁决**：Risk层对一个不可变TradeIntent给出的可追溯批准、降低、延迟、人工审查或阻止结果；不是订单或成交。
- **RiskApprovedTradeIntent / 已通过风险审查的交易意图**：供未来Order Construction识别风险门已通过的类型合同；仍需人工确认和后续安全检查，不是执行授权。
- **Risk authority / 风险权限**：安全否决和降低风险的权限；不代表Risk可以扩大交易、生成Alpha、修改Factor/Decision或直接下单。
- **Look-ahead bias / 前视偏差**：计算历史时使用了当时尚不可获得的信息。Factor输入必须显式记录Bar何时完成并可用。
- **Cycle operational activation / 周期正式生效（规划术语，未实现）**：PROPOSAL-023中系统开始把股票按新轮状态运行的时间。反转在确认日2收盘后成立，新轮从下一个交易日（第3日）正式生效；确认日1和2的历史Decision、Risk或未来成交不能被追溯改写。
- **Cycle mathematical movement reference / 周期数学参考点（规划术语，未实现）**：用于计算新轮累计实际变化的固定价格/时间。确认反转的新轮使用反转前最后一个有效高点（下跌轮）或低点（上涨轮），因此可以包含两个确认日已经发生的变化；公式为`(当前价格-数学参考价格)/数学参考价格`，不是每日涨跌幅求和。它与周期正式生效日不是同一概念。
- **Cycle extreme / 周期极值（规划术语，未实现）**：上涨周期已经观察到的最高完成价格，或下跌周期已经观察到的最低完成价格；它是判断反向波动和保存反转证据的基准。
- **Per-asset volatility range / 股票专属波动范围（规划术语，未实现）**：由精确算法版本和股票参数版本决定的波动尺度，用于区分普通波动和反转候选；具体估计器、窗口、数值和门槛映射尚未批准。
- **Reversal candidate / 反转候选（规划术语，未实现）**：相对当前周期极值的反向变化达到股票专属门槛后形成的待确认状态；它不是已经发生的周期切换。
- **Two-trading-day reversal confirmation / 两交易日反转确认（规划术语，未实现）**：第一个已完成交易日收盘越过门槛记为确认日1，下一个交易日收盘仍在门槛外才在确认日2完成确认；新轮从第3个交易日正式生效。若第二次收盘返回门槛内则取消候选。
- **Confirmation-period buffer / 确认期缓存（规划术语，未实现）**：临时保存确认日1和2的价格及判断证据。确认成功时，这些观察被归入新轮从反转极值开始的数学进度；确认失败时只取消新轮归属，原始行情和已经发生的线性Decision、Risk结果或未来成交历史仍保留。
- **Linear adjustment region / 线性调整区域（规划术语，未实现）**：未触发/确认反转时仍允许使用的基础目标持仓调整区域；其精确宽度、方向、斜率和仓位参数尚未批准。
- **Accelerating adjustment region / 加速调整区域（规划术语，未实现）**：符合已建立周期条件后可使用的更快但有限、有界的目标持仓调整区域；它与线性区域属于一条连续规则，同一次计算只应用一个区域。
- **Frozen asset / 封存股票（规划术语，未实现）**：每日允许交易次数为零、但价格、波动、数学状态和反转/恢复证据继续更新的股票状态；进入、退出和人工覆盖规则尚未批准。
- **Spectral volatility Factor / 频谱波动Factor（已实现、锁定禁用）**：PROPOSAL-023规划版本1.2–1.24批准并由PROPOSAL-024实现的单股票研究Factor。它对60/120/250个完整交易日分别保存趋势基线、两片段Welch、同网格完整窗口傅里叶诊断、主峰/竞争峰、振幅和剩余MAD证据。R1无额外平滑，使用8 ULP并列判定、80%分离竞争峰多周期判定、对称20%方法与跨窗口比较、clique支持、等效对数振幅和分离状态；它仍不能直接切换周期、计算仓位或产生买卖。
- **Hann window / Hann窗（规划术语，未实现）**：在频谱计算前逐点乘以平滑权重，降低窗口边缘突然截断造成的假频率，不删除或改写原始行情。Welch片段和完整窗口诊断均使用各自长度的周期型定义`w[n]=0.5-0.5*cos(2*pi*n/N)`；原值、系数、加权值和实现版本都保存。Welch片段随后按已批准规则尾部补零，完整窗口诊断不补零。
- **P23-1 R1 design baseline / P23-1 R1设计基线（已实现、锁定禁用）**：用户于2026-07-31批准的完整数学/数据定义，对应PROPOSAL-023规划版本1.24、PROPOSAL-024 P23-1A–D和PROPOSAL-025 P23-1E-A。R1 v1.0.0保留原先不含评估日的窗口；R1 v1.1.0把最新已完成评估日纳入60/120/250窗口，其他公式不变。它没有状态、仓位、Decision、Risk、回测或交易消费者。

- **Manual latest-session spectral preview / 人工最新交易日频谱预览（已实现、禁用研究）**：用户明确选择一只股票和`LOCAL_ONLY`或每次点击的`FETCH_AND_FREEZE_READ_ONLY`，系统准备精确IEX Daily Raw+Split/公司行动证据，运行R1 v1.1.0，保存一个完整`FACTOR_PREVIEW` Run并可重启查看。它不是自动刷新、批量比较、回测或交易信号。
- **Welch segment-spectrum average / Welch片段频谱平均（规划术语，未实现）**：PROPOSAL-023规划版本1.16规定，同一窗口的前片段和后片段分别产生功率频谱后，对相同频点`k`使用等权算术平均：`P_welch[k]=(P_leading[k]+P_trailing[k])/2`。两份单独频谱和平均频谱都保存，不因片段更新、质量评价或主观判断改变二分之一权重。规划版本1.17进一步规定任一片段频谱无效时，所属窗口无效且不能只使用另一个片段；每个片段和窗口的状态、可用证据与错误原因均保存，其他独立窗口不受影响。频谱归一化和尺度仍未批准。
- **Actual spectral power and relative power share / 实际频谱功率与相对功率占比（规划术语，未实现）**：PROPOSAL-023规划版本1.18规定每个有效Welch平均频谱同时保留两套数据。实际功率需要按以后批准的精确公式校正Hann窗影响，用于振幅研究；相对占比只在允许周期对应的频点集合`E`内计算：`S_welch[k]=P_welch[k]/sum(P_welch[j] for j in E)`，合计为1（100%），用于15%/30%强弱分类。两套数据不能互相覆盖或替代。规划版本1.19规定分母为零时实际功率仍有效，相对占比状态为`ZERO_ELIGIBLE_POWER`且没有百分比向量和强弱等级；这不是计算错误，也不单独断言是否存在稳定周期。精确Hann能量校正、单边频谱倍增、单位和边界频点仍未批准。
- **ZERO_ELIGIBLE_POWER / 允许范围零总功率（规划状态，未实现）**：频谱实际功率计算有效，但允许周期频点集合`E`内的功率总和恰好为零。此时实际功率证据照常保存，相对占比无法定义且不生成全零或其他虚假分布，也不产生15%/30%等级。它与数据缺失、片段无效、计算错误以及稳定/不稳定周期结论分开。
- **One-sided squared-magnitude spectrum / 单边平方幅值频谱（规划术语，未实现）**：P23-1的Welch和完整窗口诊断实际功率表达。对`y[n]=x[n]w[n]`保存复数FFT `Y[k]`，以Hann相干增益平方`C_w=abs(sum(w[n]))^2`校正为`P_two[k]=abs(Y[k])^2/C_w`；单边结果保留零频点原值、把有不同负频率镜像的正频点乘二，并在偶数FFT长度时保留Nyquist原值。单位为`log-price-residual^2`而非频率密度；主峰邻域按R1换算等效对数半振幅。
- **FFT_PADDING_ONLY / FFT专用补零（规划术语，未实现）**：PROPOSAL-023规划版本1.21规定的计算标记。每个Welch片段完成Hann加权后，只在尾部补零到所属完整窗口长度：本候选分别补`40..59`、`80..119`、`167..249`，得到`N_fft=60/120/250`。这些零不参与Hann系数或相干增益求和，不是Market Bar、价格、交易观察或新增信息，也不提升真实分辨能力；原始加权片段、补零序列、范围和掩码均保存。
- **Welch frequency/period grid / Welch频率与周期网格（规划术语，未实现）**：以完整窗口长度`W`为FFT长度时，频点`k`对应`f[k]=k/W`次/每个已完成交易观察，非零频点对应`T[k]=W/k`个已完成交易观察。`k=0`没有有限周期，不能作为候选。PROPOSAL-023规划版本1.21按包含边界的`4<=T[k]<=W/3`选择允许范围，因此60、120、250日窗口的精确频点集合分别为`3..15`、`3..30`和`3..62`；完整映射和每个频点的允许性都需保存。
- **Spectral half-amplitude / 频谱半振幅（已实现研究证据）**：R1定义的等效对数半振幅为`a_log=sqrt(2*P_neighborhood)`，表示候选周期相对趋势中线的功率等效单侧幅度，不是假装观察到精确高低点。它与完整对数峰谷跨度及多个价格域表达分别保存。
- **Full peak-to-trough amplitude / 完整峰谷振幅（规划术语，未实现）**：R1同时保存`2*a_log`对数峰谷跨度、`exp(a_log)-exp(-a_log)`趋势中线相对完整跨度和`exp(2*a_log)-1`谷到峰收益率等不同分母的表达。Factor不把它们统称为一个“波动百分比”，也不替未来状态规则选择口径。
- **Residual volatility / 剩余波动（规划术语，未实现）**：去除趋势和候选周期后仍无法由频谱规律解释的变化。规划版本1.3/1.4/1.10使用每日对数收益率剩余变化的MAD作为初始稳健尺度，并同时保存原始MAD和标准化MAD；异常观察不删除。正常波动范围不能只取频谱峰值，必须把剩余波动单独保存并纳入候选版本比较。
- **Raw and standardized MAD / 原始与标准化MAD（已实现研究证据）**：对趋势基线或去周期后的日对数剩余变化`e_i`，原始MAD为`median(|e_i-median(e)|)`，标准化MAD精确为`原始MAD×1.4826`；两个值和常数同时保存。float64计算与IEEE-hex证据按R1保存；零MAD是有效`ZERO_RESIDUAL_MAD`，P23-1不加最小地板，也不把`1.4826`当作反转倍数。
- **Trailing least-squares trend / 尾随最小二乘趋势（规划术语，未实现）**：PROPOSAL-023规划版本1.5/1.6为60、120、250日窗口分别拟合的直线趋势。它只读取截至计算时已经完成的对数收盘价，并选择使所有纵向偏差平方和最小的截距和斜率；结果保存截距、斜率、拟合值与逐点偏差。各窗口独立拟合，不能使用未来数据、共用一条直线或暗中改变观察权重；横轴使用按时间排序的交易观察序号`0..n-1`。
- **Trading-observation index / 交易观察序号（规划术语，未实现）**：PROPOSAL-023规划版本1.6批准的最小二乘横轴。有效窗口内已完成的交易日观察按时间排序为`0,1,2...`，周末和已确认交易所休市日不占序号；原始日期、Session和Bar ID仍完整保存。规划版本1.7规定预期交易日缺失Bar时，包含缺口的窗口不能继续作为有效连续窗口。
- **Data-incomplete spectral window / 数据不完整的频谱窗口（规划术语，未实现）**：经批准的交易日历确认某日应交易、但窗口缺少必要Bar时保存的失败可见结果。该窗口不插值、不填充、不跳过计算；不含缺口的其他窗口可独立计算。数据补齐后建立新Run，旧记录不覆盖。它表示“无法计算”，不同于完整数据计算后得到“没有稳定周期”。
- **Versioned U.S. exchange calendar / 版本化美国交易所日历（P23-1已实现）**：P23-1 R1定义`US_EQUITIES_REGULAR_V1`，由有界版本的`exchange_calendars`/`XNYS`日程支持，保存正式开收盘、节假日、临时休市、提前收盘、依赖版本、完整日程指纹和显式股票/ETF映射；没有通用代码回退，也不自动发现交易所。
- **Split-adjusted research close / 拆股调整研究收盘价（已实现研究证据）**：P23-1首个频谱候选使用Alpaca拆股调整日收盘价，保留同维度原始Bar和冻结公司行动响应。它不做分红价格调整；分红只产生可见警告，其他会改变价格/身份的公司行动使相关窗口无效。每份证据明确标为`POINT_IN_TIME_OBSERVED`、`RETROSPECTIVE_ADJUSTED`或`UNVERIFIED_ADJUSTMENT`，不把事后下载伪装成当时已知。
- **Point-in-time observed / 当时已观察（规划状态，未实现）**：所需Bar、交易日历和拆股证据均在Run的`as_of_utc`之前由系统不可变捕获。只有这种标签能证明本系统当时拥有这些输入；旧日期本身不能证明无前视偏差。
- **Retrospective adjusted / 事后调整研究（规划状态，未实现）**：系统在历史时点之后才获取或重建了部分调整证据。它可以用于明确标注的研究比较，但不能宣称是当时可用或point-in-time安全的回测输入。
- **Equivalent log half-amplitude / 等效对数半振幅（规划术语，未实现）**：由候选峰邻域功率按`a_log=sqrt(2*P_neighborhood)`换算的等效趋势中线到单侧波峰/波谷幅度。它是功率等效量，不是已观察到的最高减最低；对数半振幅、对数峰谷跨度和不同分母的价格域百分比必须分开命名和保存。
- **No stable cycle / 没有稳定周期（规划术语，未实现）**：当频率峰值过弱、不稳定或数据不足时的显式研究状态；系统不得为了得到结果而强行指定一个波动周期。
- **Five-bin Welch peak neighborhood / Welch五频点主峰邻域（规划术语，未实现）**：唯一最强允许频点`k*`请求`k*-2..k*+2`，有效成员只取与允许集合`E`的交集，并分别汇总功率/占比、记录边缘截断。8 ULP内多个最强点返回`TIED_STRONGEST_BINS`；不重叠竞争邻域达到主邻域80%返回`MULTIPLE_COMPARABLE_PEAKS`。两者都保存证据且不强选一个周期。
- **Spectral dominance / 频谱集中程度（规划术语，未实现）**：候选周期附近解释的合格频率范围内波动占比。规划版本1.22把唯一最强频点五频点邻域内的相对占比之和定义为邻域集中程度`D_neighborhood`，只汇总仍在允许集合`E`内的成员。规划版本1.23规定`0<=D<0.15`为`WEAK`，`0.15<=D<0.30`为`CANDIDATE`，`0.30<=D<=1`为`STRONG`；刚好15%属于候选、刚好30%属于强。没有定义`D_neighborhood`时不产生等级，显示层舍入后的百分比不能代替实际计算值。
- **Cross-window support / 跨窗口支持（规划术语，未实现）**：只有Welch与完整窗口诊断各自达到候选/强且周期满足对称距离`2*|T_a-T_b|/(T_a+T_b)<=20%`的窗口才参与。至少两个窗口必须构成互相兼容的pairwise clique；若只形成60↔120、120↔250而60↔250失败的链，结果为`AMBIGUOUS_CROSS_WINDOW_SUPPORT`而不是稳定周期。
- **Multiple comparable peaks / 多个相近强峰（规划状态，未实现）**：除主峰外存在一个五频点邻域不重叠的竞争峰，且其邻域占比至少达到主峰的80%。系统保存两个节奏并返回`MULTIPLE_COMPARABLE_PEAKS`，不任意选择一个单周期。
